<h2 align="center">⚙️ Como Executar o Projeto</h2>
1. Clone o repositório

```bash
$ git clone https://github.com/Camilay3/calculadoraDeNotas.git
```

2. Instale as dependências e execute o servidor Angular

```bash
# Navegue até a pasta
> cd calculadoraDeNotas

# Pré-requisitos: Node.js e Angular CLI
> npm install
> ng serve
```
4. Acesse http://localhost:4200
